DNA origami sequence Pareto package, generated 2026-11-10.

The ZIP contains 1,126 Pareto-front candidates across VEC/DBS, 6HB/rectangle, and short/nick-joined topologies. One CSV includes scaffold sequences, all four metrics, and each candidate's within-front TOPSIS rank and score. It also contains eight sequence-specific SNUPI caDNAno JSON/CSV design inputs, one TOPSIS-rank-1 candidate for each pool/structure/topology combination.

TOPSIS is a within-pool, within-topology compromise ranking over the Pareto candidates. It does not imply dominance or experimental validation. See the ZIP's README.md for scope and file details.
